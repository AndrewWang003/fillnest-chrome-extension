# Cross-Agent Workflow

The complete cross-agent workflow is maintained in
`docs/agent-handoff.md`. This short, platform-neutral entry point exists so an
agent can find it without depending on a host-specific instruction mechanism.

## Start

Read `AGENTS.md`, `PROJECT_MEMORY.md`, `DEVELOPMENT.md`, then
`docs/agent-handoff.md` before planning or editing. Read the accepted task
contract and relevant ADRs for medium or large work.

## Operate

Follow the authority hierarchy, scope controls, validation commands, Git
discipline, and handoff requirements in the handoff guide. The more detailed
project rules in `AGENTS.md` remain binding.

## Maintain Continuity

Keep `DEVELOPMENT.md` current, use task records and Git for dated evidence,
and update `PROJECT_MEMORY.md` only for durable facts that a future maintainer
must know.
