# FillNest Agent Entry Point

This repository is designed to be continued by coding agents. Before proposing
or changing anything, read [the agent handoff guide](docs/agent-handoff.md).

The guide gives the required reading order, authority hierarchy, delivery
workflow, validation commands, Git discipline, safety boundaries, and the
repository-local skills to use when the hosting agent supports them.

`AGENTS.md` contains the non-negotiable project instructions. `DEVELOPMENT.md`
is the sole current-status record and must be checked immediately before work.
